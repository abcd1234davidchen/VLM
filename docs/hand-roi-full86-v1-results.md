## 結果

完整保留 86 類：6910/8640 → 7277/8640，變動 +4.2477 個百分點，修正 505 筆、退步 138 筆。這次評估不自動替換部署模型。

RGB 定位 fallback 197 支，全部保留；局部 checkpoint 重載與快取 prediction 最大差異 0。原 checkpoint 與所有輸入的 SHA256 在評估結束時再次驗證。

Artifacts：`artifacts/hand_roi_full86_v1/evaluation`；定位 metadata：`artifacts/hand_roi_full86_v1/localization/crop_manifest.json`。
